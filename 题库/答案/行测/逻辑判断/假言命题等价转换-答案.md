## 行测-逻辑判断-001

**正确选项：** C（II 和 III）

**题型：** 假言命题等价关系判断

**核心考点：** 充分条件、逆否命题、除非句式

### 标准解析

题干“只要不是合适的生长环境，就直接进入休眠状态”表示：

```text
不是合适的生长环境 → 进入休眠状态
```

设 `P` 为“不是合适的生长环境”，`Q` 为“进入休眠状态”，原命题为 `P → Q`。

- I 为 `Q → P`，属于肯定后件，不能由 `P → Q` 推出，因此不等价。
- II 为 `非Q → 非P`，是 `P → Q` 的逆否命题，因此等价。
- III “除非有合适的生长环境，否则进入休眠状态”可翻译为“不是合适的生长环境 → 进入休眠状态”，与原命题一致，因此等价。

按形式推导，等价表述为 II 和 III，对应选项 C。

### 考场思维

看到“只要 A，就 B”，先固定为 `A → B`；看到“除非 A，否则 B”，先改写为“非 A → B”。等价判断只检查原命题和逆否命题 `非B → 非A`。

### 快速判断

| 表述 | 逻辑形式 | 结论 |
| --- | --- | --- |
| 原命题 | P → Q | 等价 |
| I | Q → P | 不等价 |
| II | 非Q → 非P | 等价 |
| III | P → Q | 等价 |

### 易错点

- 把 `Q → P` 当成 `P → Q` 的逆否命题；
- 只否定前件或后件，没有同时否定并交换位置；
- 没有识别“除非 A，否则 B”的实际形式是“非A → B”。

### 知识点归纳

```text
P → Q  ⇔  非Q → 非P
```

`Q → P` 是逆命题，`非P → 非Q` 是否命题，二者都不与原命题必然等价。
