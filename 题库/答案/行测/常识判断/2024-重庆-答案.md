## 行测-2024-重庆-常识判断-012

**正确选项：** C

**答案状态：** 已找到

**解析：**

本题考查诗句典故所涉人物的时代，选对应不正确项。

- **A项正确：** "林暗草惊风，将军夜引弓。平明寻白羽，没在石棱中"出自唐代卢纶《和张仆射塞下曲·其二》，用**李广射虎**（误以石为虎，箭没石棱）典故，李广为**西汉**名将。
- **B项正确：** "闲来垂钓碧溪上，忽复乘舟梦日边"出自唐代李白《行路难（其一）》，用**姜太公（吕尚）垂钓**与**伊尹梦日**两个典故。吕尚为商末周初人，伊尹为夏末商初人，二人皆生活在秦朝建立之前，同属**先秦**。
- **C项不正确：** "怀旧空吟闻笛赋，到乡翻似烂柯人"出自唐代刘禹锡《酬乐天扬州初逢席上见赠》。"闻笛赋"指向秀闻邻人吹笛而作《思旧赋》（悼念嵇康、吕安），"烂柯人"指王质观棋、斧柄朽烂的故事，**向秀、王质均为晋代（西晋）人**，并非**东汉**；时代对应错误，为本题答案。
- **D项正确：** "求田问舍，怕应羞见，刘郎才气"出自宋代辛弃疾《水龙吟·登建康赏心亭》，用许汜求田问舍、刘备（刘郎）讥其无志的典故，许汜与刘备均为**三国**时人。

综上，对应不正确的为 C 项。

## 行测-2024-重庆-常识判断-013

**正确选项：** B

**答案状态：** 已找到

**解析：**

本题考查中国戏曲剧种、代表剧目与出处的对应关系，选错误项。

- **A项正确：** 中国戏剧五大剧种为京剧、豫剧、评剧、黄梅戏、越剧（通行说法），对应无误。
- **B项错误：** 《群英会》是依据**《三国演义》**改编的传统京剧（三国戏，"群英会蒋干中计"），并非《水浒传》；出处错位，为本题答案。
- **C项正确：** 黄梅戏代表剧目有《天仙配》《女驸马》（另有《牛郎织女》等），对应无误。
- **D项正确：** 豫剧又称河南梆子，属**梆子腔系**，与梆子腔关系紧密，对应无误。

## 行测-2024-重庆-常识判断-020

**正确选项：** C

**答案状态：** 已找到

**解析：**

- A项错误：狂犬病毒主要侵犯中枢神经系统（神经系统），并非免疫系统。
- B项错误：流感病毒主要侵犯呼吸道（呼吸系统），并非神经系统。
- C项正确：乙肝病毒主要侵犯肝脏（肝脏属消化系统），引起乙型肝炎，对应正确。
- D项错误：艾滋病毒（HIV）主要破坏免疫系统（CD4+T淋巴细胞），并非生殖系统。

## 行测-2024-重庆-常识判断-019

**正确选项：** C

**答案状态：** 已找到

**解析：**

- **C项错误（本题答案）：** 脱脂奶是去除脂肪，应对应脂肪酶；乳糖酶用于分解乳糖（低乳糖奶），与脱脂无关。
- **A项正确：** 淀粉酶水解淀粉，用于白酒/酿酒糖化。
- **B项正确：** 纤维素酶分解纤维素，用于果汁澄清（破壁）。
- **D项正确：** 蛋白酶用于加酶洗衣粉去除蛋白污渍。
