# 假言命题等价转换-考场快判

## 10秒流程

```text
找连接词 → 写箭头 → 标前后件 → 查原命题 → 查逆否命题
```

## 看到“只要……就……”

直接记为：

```text
前件 → 后件
```

例如：

```text
只要不是合适环境，就进入休眠
不是合适环境 → 进入休眠
```

## 只保留两种等价形式

```text
P → Q
非Q → 非P
```

## 三个高频陷阱

```text
Q → P       把结果倒推原因，属于肯定后件
非P → 非Q   把前件否定后推出后件否定，属于否定前件
只否定不交换位置   没有形成逆否命题
```

## 复盘提醒

- “只要”决定充分条件方向；
- “只有”要把箭头反过来；
- 逆否命题必须同时否定、交换位置；
- 等价判断看逻辑形式，不看选项表述是否听起来合理。
