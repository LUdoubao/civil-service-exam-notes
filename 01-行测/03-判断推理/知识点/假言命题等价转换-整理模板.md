# 假言命题等价转换-整理模板

## 题型定位

- **所属模块：** 判断推理·逻辑判断·翻译推理
- **常见设问：** 哪些表述与题干意思相同、哪项是题干的等价命题、哪些结论可以推出
- **核心任务：** 将自然语言翻译成条件关系，再判断原命题与逆否命题

## 一、题干拆解

### 1. 识别连接词

| 自然语言 | 逻辑形式 |
| --- | --- |
| 只要 A，就 B | A → B |
| 如果 A，那么 B | A → B |
| A 是 B 的充分条件 | A → B |
| 只有 A，才 B | B → A |
| A 是 B 的必要条件 | B → A |
| 除非 A，否则 B | 非A → B，等价于 非B → A |

### 2. 标记前件和后件

将题干压缩为：

```text
P → Q
```

其中 P 是前件，Q 是后件。不要根据语句的先后顺序或现实常识调换方向。

## 二、等价规则

原命题与逆否命题等价：

```text
P → Q  ⇔  非Q → 非P
```

因此，选项只有在以下两种情况下才可判断为与原命题等价：

1. 保持原方向 `P → Q`；
2. 同时否定并交换位置，得到 `非Q → 非P`。

## 三、常见非等价形式

| 形式 | 名称 | 是否等价 |
| --- | --- | --- |
| P → Q | 原命题 | 是 |
| 非Q → 非P | 逆否命题 | 是 |
| Q → P | 逆命题、肯定后件 | 否 |
| 非P → 非Q | 否命题、否定前件 | 否 |

## 四、考场快速判断

1. 圈出“只要、如果、只有、除非”等连接词。
2. 写出箭头，确认前件和后件。
3. 逐项判断是原命题、逆否命题，还是逆命题/否命题。
4. 只保留原命题和逆否命题，不用先判断现实内容是否常识正确。
