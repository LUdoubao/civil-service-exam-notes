<a id="gongcheng"></a>
### 工程问题

| 公式或结论 | 说明 |
| --- | --- |
| 工作总量 = 效率 × 时间 | 工程问题最基础公式，通常可把总量设为 1、最小公倍数或具体份数。 |
| 合作效率 = 各自效率之和 | 多人合作时直接相加；有离开、加入时按分段计算。 |
| 效率比 = 工作量比（时间相同） | 同时工作、时间相同，做工量之比等于效率之比。 |
| 时间比 = 效率反比（总量相同） | 完成同一任务时，效率越大，所需时间越短。 |
| 完成率 = 已完成量 / 总量 | 适合处理“剩余多少”“还需多少天”类题目。 |

### 行程问题

| 公式或结论 | 说明 |
| --- | --- |
| 路程 = 速度 × 时间 | 一切行程问题的基础。 |
| 相遇路程 = 速度和 × 相遇时间 | 两人相向而行。 |
| 追及路程 = 速度差 × 追及时间 | 同向而行，后者速度更快。 |
| 往返平均速度 = 2ab / (a + b) | 去程速度为 a，回程速度为 b。 |
| 顺水速度 = 船速 + 水速 | 流水行船高频公式。 |
| 逆水速度 = 船速 - 水速 | 常与顺水速度联立求解。 |
| 环形相遇时间 = 环形周长 / 速度和 | 环形跑道相向而行。 |
| 环形追及时间 = 环形周长 / 速度差 | 环形跑道同向而行。 |

### 利润问题

| 公式或结论 | 说明 |
| --- | --- |
| 利润 = 售价 - 成本 | 核心定义。 |
| 利润率 = 利润 / 成本 | 常写成百分数。 |
| 售价 = 成本 × (1 + 利润率) | 已知成本与利润率求售价。 |
| 成本 = 售价 / (1 + 利润率) | 反推成本常用。 |
| 折后售价 = 标价 × 折扣 | 八折即 0.8。 |
| 定价利润率与实际利润率需区分 | 存在打折、满减时尤其注意。 |
| 总利润 = 单件利润 × 销量 | 适合与销售量变化综合考查。 |

### 排列组合与概率

| 公式或结论 | 说明 |
| --- | --- |
| 分类加法原理 | 完成一件事有几类办法，各类互斥则相加。 |
| 分步乘法原理 | 完成一件事需分几步，各步独立则相乘。 |
| 排列数 A(n,m) = n! / (n - m)! | 有顺序要求。 |
| 组合数 C(n,m) = n! / \[m!(n - m)!\] | 无顺序要求。 |
| 概率 = 满足条件情况数 / 总情况数 | 等可能情形下适用。 |
| 对立事件概率 = 1 - 正面情况概率 | 适合“至少”“至多”类问题。 |

## 基础方法

基础方法的核心不是死记步骤，而是看到题干特征后快速判断最省时的切入方式。数量关系常见方法如下。

### 代入排除法

适用场景：

- 选项给出具体数值。
- 题干关系复杂，但验证条件比正向求解更快。
- 比例、年龄、利润、工程等题型都可使用。

基本思路：

1. 优先从最容易验证的条件入手。
2. 结合奇偶性、大小关系、整除性快速删选。
3. 若选项跨度大，可优先代中间值或特殊值。

延伸笔记：

- [代入排除法](./代入排除法.md)

### 数字特性法

适用场景：

- 题目涉及奇偶、倍数、余数、尾数、整除。
- 结果不需要完整求出，只需判断可能性。

常用切入点：

- 奇偶性：和差积商后的奇偶规律。
- 整除性：被 2、3、5、9 等整除的判定。
- 尾数法：关注末位数字的循环规律。
- 余数法：同余转化，减少大数计算。

延伸笔记：

- [数字特性法](./数字特性法.md)
- [整除问题](./整除问题.md)
- [余数问题](./余数问题.md)

### 方程法

适用场景：

- 题目存在明确等量关系。
- 未知量较少，列式后可直接求解。
- 行程、工程、利润、年龄、比例问题常用。

使用要点：

1. 先设最核心未知量。
2. 优先利用总量关系、差量关系和倍数关系列方程。
3. 设未知时尽量避免引入过多变量。

延伸笔记：

- [方程法](./方程法.md)

### 特值法

适用场景：

- 题目只给比例、百分比、分数关系。
- 总量未知且不影响结论时。

常见设法：

- 设总量为 1、100 或分母最小公倍数。
- 比例关系直接设为若干份。
- 工程问题常把工作总量设为效率分母的最小公倍数。

延伸笔记：

- [特值法](./特值法.md)

### 比例法

适用场景：

- 多组对象在相同时间、相同效率或同一总量下比较。
- 题干中“增加几成”“缩小为原来的几分之几”“甲乙比”为高频信号。

常见结论：

- 时间相同，工作量比等于效率比。
- 总量相同，时间比等于效率反比。
- 路程相同，时间比等于速度反比。

延伸笔记：

- [比例法](./比例法.md)
- [比例倍数问题](./比例倍数问题.md)

### 枚举与列表法

适用场景：

- 排列组合、概率、容斥中情况数有限。
- 题目容易漏情况，需要系统列举。

使用要点：

1. 先确定分类标准，避免重复与遗漏。
2. 固定一个变量，再逐步展开。
3. 适合与加法原理、乘法原理配合使用。

延伸笔记：

- [枚举法](./枚举法.md)
- [排列组合问题](./排列组合问题.md)

### 图示与表格法

适用场景：

- 行程、工程、年龄、浓度等关系较绕。
- 文字描述较长，直接列式容易混乱。

常见做法：

- 行程问题画线段图。
- 工程问题列“效率-时间-总量”表。
- 浓度问题列“溶液-溶质-浓度”表。
- 年龄问题画时间轴。

延伸笔记：

- [图示法](./图示法.md)
- [表格法](./表格法.md)
