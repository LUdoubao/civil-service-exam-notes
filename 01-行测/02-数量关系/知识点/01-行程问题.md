# 01-行程问题

行程问题是数量关系中的高频题型，本质上围绕 `路程 = 速度 × 时间` 展开。无论是相遇追及、流水行船，还是环形跑道、扶梯问题，核心都在于先判断运动方向和对象关系，再选择“速度和”或“速度差”列式。

## 核心公式表

### 基础行程

| 公式 | 说明 | 常见用途 |
| --- | --- | --- |
| 路程 = 速度 × 时间 | 行程问题总公式。 | 已知两项求第三项。 |
| 速度 = 路程 / 时间 | 用于反推速度。 | 已知路程和时间求速度。 |
| 时间 = 路程 / 速度 | 用于反推用时。 | 已知路程和速度求时间。 |
| 平均速度 = 总路程 / 总时间 | 不能直接对速度做算术平均。 | 分段行程、往返问题。 |
| 等距离往返平均速度 = 2ab / (a + b) | 去程速度为 a，回程速度为 b。 | 往返速度类题目。 |

### 相遇追及

| 公式 | 说明 | 常见用途 |
| --- | --- | --- |
| 相遇时间 = 初始距离 / 速度和 | 两人相向而行。 | 第一次相遇时间。 |
| 相遇路程 = 速度和 × 相遇时间 | 与上式对应。 | 反推初始距离或时间。 |
| 追及时间 = 初始距离 / 速度差 | 两人同向而行，后者更快。 | 追上所需时间。 |
| 追及路程 = 速度差 × 追及时间 | 与上式对应。 | 反推距离差。 |
| 同地反向相遇周期 = 全程 / 速度和 | 适用于折返或固定全程运动。 | 多次相遇问题。 |

### 流水行船

| 公式 | 说明 | 常见用途 |
| --- | --- | --- |
| 顺水速度 = 船速 + 水速 | 顺流而下。 | 求顺流时间或距离。 |
| 逆水速度 = 船速 - 水速 | 逆流而上。 | 求逆流时间或距离。 |
| 船速 = (顺水速度 + 逆水速度) / 2 | 已知顺、逆水速度。 | 反推静水船速。 |
| 水速 = (顺水速度 - 逆水速度) / 2 | 已知顺、逆水速度。 | 反推水流速度。 |
| 同船同程时，顺水时间 < 逆水时间 | 时间大小规律。 | 快速判断选项。 |

### 环形行程

| 公式 | 说明 | 常见用途 |
| --- | --- | --- |
| 同向追及时间 = 环形周长 / 速度差 | 在环形跑道同向运动。 | 第一次追上时间。 |
| 反向相遇时间 = 环形周长 / 速度和 | 在环形跑道反向运动。 | 第一次相遇时间。 |
| 第 n 次相遇时间 = n × 环形周长 / 速度和 | 反向多次相遇。 | 多次相遇问题。 |
| 第 n 次追及时间 = n × 环形周长 / 速度差 | 同向多次追及。 | 多次追及问题。 |

### 扶梯问题

| 公式 | 说明 | 常见用途 |
| --- | --- | --- |
| 扶梯总级数 = (人速 + 梯速) × 时间 | 人与扶梯同向上行。 | 求总级数或扶梯速度。 |
| 扶梯总级数 = (人速 - 梯速) × 时间 | 人逆着扶梯方向行走。 | 求总级数或人的速度。 |
| 扶梯静止时总级数 = 人速 × 时间 | 扶梯不动时退化为普通路程问题。 | 对照理解速度关系。 |
| 同一扶梯总级数不变 | 题干变化的是速度与时间，不是总级数。 | 多人上下扶梯综合题。 |

## 解题技巧提示

### 画图法

行程问题最怕文字绕。遇到多人、多方向、折返、相遇类题目时，优先画线段图或环形示意图，至少标清以下信息：

- 起点和终点。
- 运动方向。
- 初始距离或环形周长。
- 相遇点、追及点或折返点。

画图后，很多“谁和谁在靠近”“谁和谁在拉开”的关系会直接转化为速度和或速度差。

### 比例法

比例法适合以下场景：

- 同路程比较时间。
- 同时间比较路程。
- 同一对象在不同速度下的行程变化。

常见结论：

- 路程相同，速度比与时间比成反比。
- 时间相同，速度比等于路程比。
- 全程不变时，提速多少、节省多少时间，通常可以转化为比例关系。

### 方程法与列表法

当题目存在多个未知量时，可把“路程、速度、时间”整理成表格再列方程：

| 对象 | 路程 | 速度 | 时间 |
| --- | --- | --- | --- |
| 甲 | 已知/未知 | 已知/未知 | 已知/未知 |
| 乙 | 已知/未知 | 已知/未知 | 已知/未知 |

适用情形：

- 两人或多人同时运动。
- 分段加速、减速或中途停留。
- 流水行船、扶梯问题这类含“额外速度”的题目。

### 快速识别提示

| 题干关键词 | 优先想到的模型 |
| --- | --- |
| “相向而行”“迎面相遇” | 相遇问题，用速度和。 |
| “同向而行”“追上” | 追及问题，用速度差。 |
| “顺流”“逆流” | 流水行船，先拆船速和水速。 |
| “环形跑道”“第几次相遇” | 环形行程，注意周长倍数。 |
| “自动扶梯”“走上去/走下来” | 扶梯问题，总级数不变。 |

## 使用建议

- 第一步先判断题型，再决定是用总公式、速度和还是速度差。
- 第二步把题干信息整理成图或表，避免把“方向”和“对象”搞混。
- 第三步再根据题型进入对应详解笔记，例如 [相遇追及问题](./行程问题-相遇追及.md) 或 [流水行船问题](./行程问题-流水行船.md)。
