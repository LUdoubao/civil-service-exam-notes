# 常识判断-知识点汇总

> 全部常识判断知识点与题目复盘集中于本文档；每个条目只保留关键信息，格式见 [知识点汇总模板](./知识点汇总模板.md)。

## 一、法律

### 1️⃣. 古代法治典故与盛世法制

- **大类：** 法律
- **关键要点：**
  - 1. 战国秦：商鞅变法——徙木立信（立木建信）、"法必明、令必行"、奖励耕战。
  - 2. 西汉：汉律六十篇 = 萧何《九章律》9篇 + 叔孙通《傍章》18篇 + 张汤《越宫律》27篇 + 赵禹《朝律》6篇（武帝时齐备），两汉沿用近400年。
  - 3. 唐：《贞观律》（637年，长孙无忌等）——"贞观之治"法制基石；《唐律疏议》为中华法系代表。
  - 4. 明：《大明律》（洪武年间）、《明大诰》、重典治吏；"约法三章"属汉高祖刘邦，勿混。
  - 5. 解题法：抓典故关键词定人物→定朝代→比对；"约法三章"=刘邦入咸阳，是最易被张冠李戴的典故。
- **易错点：** 命题将"约法三章"（刘邦）安到朱元璋头上（2025黑龙江第18题设错方式）；汉律六十篇的四部分构成（9+18+27+6）是高频考点。
- **关联题目：** [行测-2025-黑龙江-常识判断-018](../../../题库/答案/行测/常识判断/2025-黑龙江-答案.md#行测-2025-黑龙江-常识判断-018) → 正确选项 D（错因：不悉"约法三章"属刘邦而非朱元璋）

## 二、科技

### 1️⃣. 古代发明制造与“人工智能历史渊源”对应（算盘·八卦·候风地动仪·水运仪象台）

- **大类：** 科技
- **关键要点：**
  - 1. 算盘——中国古代十进制手动计算工具（横梁分上下珠，上珠当5、下珠当1，右起个/十/百/千/万为十进制），可视为“十进制机械式手动计算器”。
  - 2. 八卦——由阴爻(––)、阳爻(—)两符号三叠成卦，阳爻=1、阴爻=0可对应3位二进制（六十四卦对应6位二进制），被视作二进制思想的东方渊源。
  - 3. 候风地动仪——东汉张衡(132年)发明，以都柱/候风摆感地震波触发牙机，龙吐丸定震向并敏感初波(P波)微震，即“地震方位自动检测与微震敏感报警器”。
  - 4. 水运仪象台——北宋苏颂、韩公廉制，以**漏刻水力驱动**（水车、筒车、凸轮、天平秤杆等原理），集天文观测/演示/报时于一体；题干称“重力驱动”不准确（应为水力驱动）。
  - 5. 解题法：判“驱动方式”与“功能定位”是否匹配；水运仪象台是水力而非重力，是最常设错点。
- **易错点：** 把水运仪象台误记为“重力驱动”（实为水力/漏刻驱动）是本题唯一错误项表述（2022云南第15题仅④错，答案选A=1项错误）；算盘十进制、八卦二进制、候风地动仪测震三项均正确。
- **关联题目：** [行测-2022-云南-常识判断-015](../../../题库/答案/行测/常识判断/2022-云南-答案.md#行测-2022-云南-常识判断-015) → 正确选项 A（错因：不悉水运仪象台为水力驱动而非重力驱动，仅④一项错误）

### 2️⃣. 瑟弦发声原理与文献印证（粗细·张力·音高）

- **大类：** 科技
- **关键要点：**
  - 1. 弦的音高由弦的**粗细**（越细振动越快、音越高）与**张力**（张力越大、音越高）共同决定；瑟二十五弦、弦下有柱，移柱/调张力即可变调。
  - 2. "清庙之瑟，朱弦而疏越，壹倡而三叹"（《礼记·乐记》）——只述用熟丝弦、稀调音孔与领唱应和之形制，**未涉及音高与粗细/张力关系**，属"未体现原理"项。
  - 3. "夫瑟以小弦为大声，以大弦为小声"（《韩非子·外储说左下》）——同长下细弦音高更高，体现**粗细与音高成反比**。
  - 4. "瑟前其柱则清，却其柱则浊"（《月令章句》）——前柱增张力→音升（清），却柱减张力→音降（浊），体现**张力与音高成正比**。
  - 5. "缓其商弦，与宫同音"（《春渚纪闻》）——松商弦减张力使其降至宫音高度，体现**单变张力即可变音高**。
  - 6. 解题法：判各句是否提到"弦的粗细/张力→音高变化"；只讲形制、演奏场景而无此关系者即"未体现"。
- **易错点：** 华图/金标尺等将选项重排（清庙之瑟列为C项）致标"答案C"；公考真题库原序清庙之瑟为**A项**、答案页亦标**A**，二者实质一致，均指"清庙之瑟"未体现发声原理（2024天津第65题）。
- **关联题目：** [行测-2024-天津-常识判断-065](../../../题库/答案/行测/常识判断/2024-天津-答案.md#行测-2024-天津-常识判断-065) → 正确选项 A（错因：不悉"清庙之瑟"句仅述形制、未涉音高与粗细/张力关系）


### 3️⃣. 光学现象的分类（直线传播·干涉·偏振·衍射）

- **大类：** 科技
- **关键要点：**
  - 1. 光沿直线传播：小孔成像、影、日食月食等（几何光学）。
  - 2. 光的干涉：薄膜（肥皂泡、油膜）前后表面反射光叠加形成彩色条纹。
  - 3. 光的偏振：3D电影眼镜利用偏振光，左右眼接收不同偏振方向画面。
  - 4. 光的衍射：光绕过障碍物，泊松亮斑（不透光圆屏轴线亮斑）是其典型。
- **易错点：** 题干“光的性质与其他三项不同”常设直线传播（几何光学）与波动性（干涉/偏振/衍射）的对立；B、C、D三项均属波动性。
- **关联题目：** [行测-2022-云南-常识判断-013](../../../题库/答案/行测/常识判断/2022-云南-答案.md#行测-2022-云南-常识判断-013) → 正确选项 A（错因：不悉小孔成像属直线传播、其余三项属波动性（干涉/偏振/衍射））

### 4️⃣. 生活中的光现象解释（散射·反射·折射）

- **大类：** 科技
- **关键要点：**
  - 1. 天空蓝色：大气对短波蓝紫光瑞利散射更强。
  - 2. 早晚太阳红色：厚大气层散射掉蓝紫光、红光穿透，属散射非反射。
  - 3. 小孔成像：光的直线传播，非衍射。
  - 4. 湿衣颜色变深：水填充孔隙减少反射、增加吸收，光的频率不变。
- **易错点：** 将早晚红色归为“反射”、将小孔成像归为“衍射”是常见错配（2020山西第101题选B）。
- **关联题目：** [行测-2020-山西-常识判断-101](../../../题库/答案/行测/常识判断/2020-山西-答案.md#行测-2020-山西-常识判断-101) → 正确选项 B（错因：不悉天空蓝/早晚红为散射、小孔成像为直线传播）

### 5️⃣. 声音的三特性（音调·响度·音色）

- **大类：** 科技
- **关键要点：**
  - 1. 音调：由频率决定；吹箫按孔改变空气柱长度→改变频率→改变音调。
  - 2. 响度：由振幅/距离决定。
  - 3. 音色：由发声体材料结构决定，是辨别不同人/乐器的依据。
  - 4. 解题法：辨人/辨乐器→音色；按孔→音调。
- **易错点：** 把“辨人”误归音调、把“按孔”误归音色（2024黑龙江第11题选D，三者均不同）。
- **关联题目：** [行测-2024-黑龙江-常识判断-011](../../../题库/答案/行测/常识判断/2024-黑龙江-答案.md#行测-2024-黑龙江-常识判断-011) → 正确选项 D（错因：不悉辨人靠音色、按孔改变音调、男中音女高音三者均不同）

### 6️⃣. 机械波与电磁波（真空中传播条件）

- **大类：** 科技
- **关键要点：**
  - 1. 机械波（声波、地震波、水波）传播需介质，不能在真空传播。
  - 2. 电磁波（微波、无线电波、光波、红外、紫外）不需介质，真空中以光速传播。
  - 3. 超声波是声波（机械波），需介质。
- **易错点：** 题干“均不能在真空中传播”须两项皆为机械波；含任一电磁波即错（2024吉林第15题选C，声波+地震波）。
- **关联题目：** [行测-2024-吉林-常识判断-015](../../../题库/答案/行测/常识判断/2024-吉林-答案.md#行测-2024-吉林-常识判断-015) → 正确选项 C（错因：不悉声波与地震波均属机械波、不能在真空传播）

### 7️⃣. 电磁波的性质与应用

- **大类：** 科技
- **关键要点：**
  - 1. 所有电磁波真空中速度均为c。
  - 2. 红外线：热效应，用于遥控、热成像。
  - 3. 紫外线：消毒、荧光。
  - 4. 雷达：无线电波发射并接收反射回波测距。
- **易错点：** 误以为“微波真空速度小于可见光”“紫外线用于遥控/热成像”（2020北京第10题选D）。
- **关联题目：** [行测-2020-北京-常识判断-010](../../../题库/答案/行测/常识判断/2020-北京-答案.md#行测-2020-北京-常识判断-010) → 正确选项 D（错因：不悉微波与可见光真空中同速、遥控/热成像用红外线）

### 8️⃣. 常见探测设备原理（热像仪·声呐·雷达·金属探测）

- **大类：** 科技
- **关键要点：**
  - 1. 热像仪：探测红外辐射，夜间可用。
  - 2. 声呐：声波水下测距，主用于水中。
  - 3. 雷达：无线电波直线传播+反射测距。
  - 4. 地下金属探测：电磁感应（涡流）。
- **易错点：** 声呐“主要用于陆地及空中”为错（实际主用于水下），2021国考副省级第15题选B。
- **关联题目：** [行测-2021-国考副省级-常识判断-015](../../../题库/答案/行测/常识判断/2021-国考副省级-答案.md#行测-2021-国考副省级-常识判断-015) → 正确选项 B（错因：不悉声呐主用于水下探测而非陆地空中）

### 9️⃣. 核电站与核能

- **大类：** 科技
- **关键要点：**
  - 1. 商用核电站利用铀核裂变（非聚变）释放能量。
  - 2. 能量链：核反应堆→蒸汽→汽轮机→发电机（机械能→电能）。
  - 3. 核废料须专门处置（深地质封存），不可混生活垃圾。
  - 4. 汽轮机喷出水雾为液化，非分子扩散。
- **易错点：** 误以为“利用核聚变”“核废料同生活垃圾处理”（2025云南第19题选A）。
- **关联题目：** [行测-2025-云南-常识判断-019](../../../题库/答案/行测/常识判断/2025-云南-答案.md#行测-2025-云南-常识判断-019) → 正确选项 A（错因：不悉核电站为裂变发电、核废料须专门处置）

### 1️⃣0️⃣. 生活中的力学与电学现象

- **大类：** 科技
- **关键要点：**
  - 1. 白炽灯钨丝升华变细→横截面积减小→电阻变大（R=ρL/S）。
  - 2. 拱形结构受压，桥拱不“增加桥墩拉力”。
  - 3. 风筝上升机械能因空气阻力而减小。
  - 4. 压力=重力，与底面积无关（底面积只改压强）。
- **易错点：** 误以为塔基越大“压力越小”（2025天津第58题选B）。
- **关联题目：** [行测-2025-天津-常识判断-058](../../../题库/答案/行测/常识判断/2025-天津-答案.md#行测-2025-天津-常识判断-058) → 正确选项 B（错因：不悉钨丝升华变细电阻变大、压力与底面积无关）

### 1️⃣1️⃣. 洗澡中的物理现象（表面张力·伯努利·浮力·散射）

- **大类：** 科技
- **关键要点：**
  - 1. 水珠球形：表面张力使表面积最小。
  - 2. 伯努利原理：流速大压强小（淋浴有力非“压强增加”）。
  - 3. 浮力=排开水重力（阿基米德原理）。
  - 4. 水雾使光线散射而视线模糊。
- **易错点：** 误以为“流速增加压强增加”（实为减小），2025宁夏第26题选C。
- **关联题目：** [行测-2025-宁夏-常识判断-026](../../../题库/答案/行测/常识判断/2025-宁夏-答案.md#行测-2025-宁夏-常识判断-026) → 正确选项 C（错因：不悉流速大压强小（伯努利））

### 1️⃣2️⃣. 水的比热容大的应用

- **大类：** 科技
- **关键要点：**
  - 1. 水比热容大，升/降温慢，善于吸放热。
  - 2. 应用：发动机水循环降温、暖水袋取暖。
  - 3. 擦身降温主因是蒸发吸热，非比热容。
- **易错点：** 把“擦身降温”算入比热容应用（2021新疆第18题选D，仅③④）。
- **关联题目：** [行测-2021-新疆-常识判断-018](../../../题库/答案/行测/常识判断/2021-新疆-答案.md#行测-2021-新疆-常识判断-018) → 正确选项 D（错因：不悉比热容大用于降温/取暖，擦身降温主因是蒸发）

### 1️⃣3️⃣. 酿酒发酵与物态变化

- **大类：** 科技
- **关键要点：**
  - 1. 酿酒：酒曲中酵母菌等微生物发酵糖类产酒精（微生物作用）。
  - 2. 雪熔化为水吸热（非放热）。
  - 3. 炉火燃烧是化学能→内能（非内能→化学能）。
  - 4. “绿蚁”为酒面浮沫，非食用调色剂。
- **易错点：** 误以为“醅酒”非微生物作用、雪→水放热（2020国考副省级第17题选B）。
- **关联题目：** [行测-2020-国考副省级-常识判断-017](../../../题库/答案/行测/常识判断/2020-国考副省级-答案.md#行测-2020-国考副省级-常识判断-017) → 正确选项 B（错因：不悉酿酒靠微生物发酵、雪熔化吸热）

### 1️⃣4️⃣. 古诗文中的物理知识对应（光学·力学·分子运动）

- **大类：** 科技
- **关键要点：**
  - 1. “残阳铺水中”=平面镜成像（反射）；凸透镜=折射→二者不同。
  - 2. “会挽雕弓如满月”/蹦床=弹性势能与动能相互转化。
  - 3. “两岸青山相对出”/跑步机=运动与静止的相对性。
  - 4. “花气袭人知骤暖”/温度计=分子热运动（温度越高越剧烈）。
- **易错点：** 把“残阳铺水中”与凸透镜（折射）判为“相同”（实为反射vs折射），2023浙江第10题选A（不相同项）。
- **关联题目：** [行测-2023-浙江-A类-常识判断-010](../../../题库/答案/行测/常识判断/2023-浙江-A类-答案.md#行测-2023-浙江-A类-常识判断-010) → 正确选项 A（错因：不悉残阳铺水中为反射、凸透镜为折射，二者物理知识不同）

### 1️⃣5️⃣. 诗句中的生物学现象（保护色·向光性·分解·温度）

- **大类：** 科技
- **关键要点：**
  - 1. “黄蝶入菜花”=保护色（体色与环境一致），非拟态。
  - 2. “红杏出墙”=植物的向光性。
  - 3. “落红化泥”=微生物（分解者）分解作用。
  - 4. “山寺桃花”=温度影响植物开花。
- **易错点：** 把黄蝶菜花归为“拟态”（应为保护色），2022重庆第19题选A。
- **关联题目：** [行测-2022-重庆-常识判断-019](../../../题库/答案/行测/常识判断/2022-重庆-答案.md#行测-2022-重庆-常识判断-019) → 正确选项 A（错因：不悉黄蝶入菜花为保护色而非拟态）

### 1️⃣6️⃣. 矿物及其制品

- **大类：** 科技
- **关键要点：**
  - 1. 稀土：17种金属元素统称，非单一元素。

### 3️⃣4️⃣. 伯努利与二次流（茶叶悖论/河流弯道）

- **大类：** 科技
- **关键要点：**
  - 1. 搅动杯中茶/汤形成二次流，底部液体向中心回流，茶叶被带向杯底中心聚集（茶叶悖论）。

  - 4. 离心力+二次流是上述现象共同物理机制（伯努利+惯性）。
- **易错点：** 误以为“外圈河床比内圈浅”（实际外圈冲刷更深）；洗衣脱水裤兜翻出属惯性/离心。

### 5️⃣3️⃣. 吊扇悬挂点拉力

- **大类：** 科技
- **关键要点：**
  - 1. 静止时：拉力=重力（平衡）。
  - 2. 转动时：叶片向下推空气，空气反作用向上托扇叶→拉力<重力。
  - 3. 转速越大，下压空气越多，反作用越大，拉力越小。
  - 4. 转速越小，下压越少，拉力越接近重力（越大），故“转速越小拉力越小”错。
- **易错点：** 误以为转速越小拉力越小（实际转速小拉力大）；①②③正确共3项。

### 2️⃣2️⃣. 中国古代建筑类型

### 3️⃣1️⃣. 宋代社会景象的可能性判断

### 3️⃣2️⃣. 历史情境可能性判断（剧种·战役·瓷器·人物年代）

- **大类：** 人文
- **关键要点：**
  - 1. 昆曲：起源于元末明初江苏昆山（昆山腔），明嘉靖年间经魏良辅改良后盛行，万历年间传入北京；明代中后期长期占据剧坛中心——明代出现昆曲班子献唱完全合理。
  - 2. 淝水之战：383 年东晋与前秦之战（今安徽寿县东南）；白起为**战国**秦国名将，不可能参考后世战役指挥。
  - 3. 粉彩瓷器：**清代康熙年间**创烧，雍正成熟、乾隆兴盛；唐代瓷器为“南青北白”（青瓷、白瓷），尚无粉彩。

  - 5. 解题法：先给各选项的“剧种/战役/器物/人物”定年代，再与题干时代比对，凡“晚于题干时代”即不可能。
- **易错点：** 命题把后世之物前置于更早朝代（2025 天津第 61 题：粉彩瓷（清）入唐、白起（战国）参考淝水之战（东晋）、王阳明与黄宗羲跨时代通信三处错位）；昆曲（明）易被误判为清代剧种。

### 3️⃣3️⃣. 历史情境可能性判断（补服·珐琅彩·投壶·茶坊年代）

- **大类：** 人文
- **关键要点：**
  - 1. 补服/补子：**始于明代**，延续至清；缀于官服前后以区别官职，文官用飞禽（一品仙鹤补）、武官用猛兽（一品麒麟补）——汉朝无补子制度。
  - 2. 珐琅彩瓷：清代康熙晚期创烧（铜胎画珐琅技法移植到瓷胎），雍正、乾隆时期产量最大。
  - 3. 投壶：士大夫宴饮时的投掷游戏兼礼仪，**战国时期较为盛行**，唐代发扬光大。
  - 4. 茶坊：唐代已出现（《封氏闻见记》载"煮茶卖之"）；施耐庵（元末明初）常去茶坊符合史实。
  - 5. 解题法：选非题先给"器物/制度/设施"定出出现年代，与题干设定时代比对，凡早于其出现年代者即"不符合史实"。
- **易错点：** 命题把明代才有的补子制度置于汉朝（2024 浙江 A 类第 14 题设错项）；投壶、珐琅彩、茶坊三项均为符合史实的干扰项，需逐项核实年代而非凭印象排除。

### 4️⃣3️⃣. 先秦史料记载与调料对应（醠-酒·椒兰-香料·饴蜜-甜·宿沙-盐）

- **大类：** 人文
- **关键要点：**
  - 1. "清醠之美，始于耒耜"——《淮南子·说林训》，醠=浊酒、清醠=过滤后的清酒，耒耜=农具，强调酿酒源于农业，对应**酒**。
  - 2. "椒兰芬苾，所以养鼻也"——《荀子·礼论》，椒=花椒、兰=兰草，均为先秦香料（焚佩以养鼻），对应**香料/香气**，非姜。
  - 3. "枣、栗、饴、蜜以甘之"——《礼记·内则》，饴=麦芽糖、蜜=蜂蜜，与枣栗同为甜味来源，对应**甜味调料**，非肉桂。
  - 4. "宿沙作煮盐"——《世本·作篇》，宿沙氏为传说中煮海为盐的部落首领，对应**盐**，非酱（先秦酱多为醢/豆酱）。
  - 5. 解题法：先释句中关键词本义（醠=酒、椒兰=香料、饴蜜=甜、宿沙=煮盐），再与选项调料比对。
- **易错点：** 命题以"望文生义"设错——把椒兰误判为姜、饴蜜误判为肉桂、宿沙煮盐误判为酱；唯"清醠-酒"正确（2025 辽宁第 24 题答案 A）。注意"醠"(àng,酒)与"醯"(xī,醋)字形相近，勿混。
- **关联题目：** [行测-2025-辽宁-常识判断-024](../../../题库/答案/行测/常识判断/2025-辽宁-答案.md#行测-2025-辽宁-常识判断-024) → 正确选项 A（错因：不悉醠=浊酒对应酒；椒兰为香料、饴蜜为甜、宿沙煮盐为盐，其余三项均错配）

### 4️⃣4️⃣. 文学作品创作年代排序（兰亭集序·滕王阁序·岳阳楼记等）

- **大类：** 人文
- **关键要点：**
  - 1. 《过秦论》——西汉贾谊；《隆中对》——西晋陈寿（约207—220）；《归去来兮辞》——东晋陶渊明。
  - 2. 《兰亭集序》——东晋王羲之（353年）；《滕王阁序》——唐代王勃（约675年）；《岳阳楼记》——北宋范仲淹（1046年）。正确序：兰亭→滕王阁→岳阳。
  - 3. 《桃花源记》——东晋陶渊明；《捕蛇者说》——唐代柳宗元；《醉翁亭记》——北宋欧阳修。
  - 4. 《铜雀台赋》——东汉末年曹植；《阿房宫赋》——唐代杜牧；《后赤壁赋》——北宋苏轼。
  - 5. 解题法：以"朝代轴"（西汉→东汉末→西晋→东晋→唐→北宋）锚定每篇作者年代，再判顺序正误。
- **易错点：** 最易错是将北宋《岳阳楼记》置于唐代《滕王阁序》之前（2021 四川第 8 题 B 项即此错误排序，为本题"错误"项）；唐赋/序早于北宋散文是高频考点。
- **关联题目：** [行测-2021-四川-常识判断-008](../../../题库/答案/行测/常识判断/2021-四川-答案.md#行测-2021-四川-常识判断-008) → 正确选项 B（错因：不悉《滕王阁序》(唐)早于《岳阳楼记》(北宋)，B 项排序颠倒，为本题"错误"项）

### 4️⃣5️⃣. 世界代表性建筑与国家对应（比萨斜塔·大本钟/格林尼治·泰姬陵·俄罗斯洋葱顶教堂）

- **大类：** 人文
- **关键要点：**
  - 1. 比萨斜塔——意大利：位于托斯卡纳省比萨城，1173 年始建，因软土地基与土层不均而倾斜，是中古世界七大奇迹之一，被誉为"将倒未倒"的钟楼。
  - 2. 大本钟（伊丽莎白塔）/格林尼治——英国：大本钟为伦敦地标钟塔（1858 年建成）；格林尼治为伦敦一区，1675 年设皇家天文台，1884 年国际经度会议定其经线为本初子午线（零度经线）、世界时区起点。
  - 3. 泰姬陵——印度：莫卧儿皇帝沙贾汗为纪念爱妃于 1631—1653 年建造的白色大理石陵墓清真寺，世界新七大奇迹之一，"白色大理石/爱情"为其标志。
  - 4. "洋葱顶"教堂——俄罗斯：洋葱形穹顶（直径大于鼓座、高大于宽、形似洋葱）是俄罗斯东正教堂最显著的造型特征，如莫斯科红场南端的瓦西里升天大教堂、圣彼得堡滴血大教堂；色彩绚丽、似童话城堡即指此类，**并非西班牙**。
  - 5. 西班牙代表性建筑：圣家族大教堂、马德里王宫、蒙特惠奇城堡等，无"洋葱顶童话城堡"特征；命题常把俄罗斯洋葱顶教堂安到西班牙头上。
  - 6. 解题法：抓描述关键词（倾斜钟楼→意大利、格林尼治/大本钟→英国、白大理石爱情陵→印度、洋葱顶童话城堡→俄罗斯），凡"国家"与关键词错配即选非项。
- **易错点：** 命题把俄罗斯东正教堂的"洋葱顶/童话城堡"特征误归于西班牙（2024 国考副省级第 19 题 D 项设错）；洋葱顶是俄罗斯而非西班牙、希腊或中东其他国家的标志。
- **关联题目：** [行测-2024-国考副省级-常识判断-019](../../../题库/答案/行测/常识判断/2024-国考副省级-答案.md#行测-2024-国考副省级-常识判断-019) → 正确选项 D（错因：不悉"洋葱顶童话城堡"为俄罗斯东正教堂特征，误系于西班牙）

### 4️⃣6️⃣. 中国传统礼制（五礼·冠礼笄礼·礼的社会作用）

- **大类：** 人文
- **关键要点：**
  - 1. "周监于二代，郁郁乎文哉！吾从周"出自《论语·八佾》，是孔子对周朝（借鉴夏、商二代）礼制丰富而有文采的赞赏，并明言"从周"。
  - 2. 五礼：吉、凶、军、宾、嘉五种礼制（源出《周礼》）。吉礼祭鬼神（五礼之首）、凶礼丧葬灾荒、军礼军事、宾礼"亲邦国"（朝觐聘享、邦交往来）、嘉礼"亲万民"（冠婚、宴飨、乡饮酒、贺庆等）。
  - 3. 嘉礼 ≠ 邦国间朝觐聘享之礼：后者属宾礼；嘉礼是节庆人事之礼（冠婚宴飨等）——此为高频设错点。
  - 4. 冠礼（男，约二十岁加冠）与笄礼（女，约十五岁及笄）分指男女成年礼；古代笄礼多于上巳节（三月三）举行。
  - 5. "礼，经国家，定社稷，序民人，利后嗣者也"出自《左传·隐公十一年》，强调礼对整合社会、建立秩序的根本作用。
- **易错点：** 命题把"邦国间朝觐聘享之礼"安到嘉礼头上（实为宾礼）；五礼的吉凶军宾嘉顺序及各自涵摄是高频考点（2025 内蒙古第 21 题 B 项即此设错）。
- **关联题目：** [行测-2025-内蒙古-常识判断-021](../../../题库/答案/行测/常识判断/2025-内蒙古-答案.md#行测-2025-内蒙古-常识判断-021) → 正确选项 B（错因：不悉"邦国间朝觐聘享"属宾礼而非嘉礼）

### 4️⃣7️⃣. 中华古籍与古籍制作（六经·经史子集·灞桥纸·雕版/活字印刷）

- **大类：** 人文
- **关键要点：**
  - 1. 孔子整理"六经"：《诗》《书》《礼》《乐》《易》《春秋》；《乐》亡佚，现传"五经"（易书诗礼春秋）传承至今。
  - 2. 经史子集是古籍按内容区分的四大部类：经（儒家经典）、史（史书）、子（诸子百家与类书）、集（诗词汇编等文集）。《宋书》（南朝梁沈约撰，二十四史之一）属**史部**而非集部。
  - 3. 纸是古籍主要载体；"灞桥纸"为西安灞桥出土西汉武帝时期麻纸，现存最古老纸张之一，距今两千多年。
  - 4. 雕版印刷术发明于隋唐（唐中后期普遍使用）；北宋毕昇发明泥活字，标志活字印刷术诞生，二者极大促进古籍制作与文化传播。
- **易错点：** 《宋书》属史部而非集部（2024 辽宁第 1 题②误将其归"集"部，为错误项）；六经中《乐》失传、仅五经传世是高频考点。

### 4️⃣8️⃣. 干支纪年与兔年相关文化常识（兔文物年代·玉兔号·《白兔赋》）

- **大类：** 人文
- **关键要点：**
  - 1. 干支纪年：十天干（甲、乙、丙、丁、戊、己、庚、辛、壬、癸）+十二地支（子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥）按顺序配对，60 年一循环；生肖（如卯=兔）12 年一循环。
  - 2. 兔年推算：2023 年为癸卯兔年（天干癸、地支卯）。2035=2023+12 仍为卯（兔）年；天干 10 循环，癸(第10)后推 12 年→12 mod 10=2→乙(第2)，故 2035 年为乙卯兔年（A 项正确）。
  - 3. 兔文物年代辨析：兔尊=西周（1992 年山西晋侯墓出土青铜礼器）；白釉兔=唐代；青玉兔镇纸=南宋。三者并非同为西周（B 项错误）。
  - 4. 玉兔号月球车：嫦娥三号月球车 2013 年命名"玉兔号"；嫦娥四号月球车 2019 年命名"玉兔二号"，二者均属"玉兔"系列（C 项正确）。
  - 5. 文学：《白兔赋》为唐代蒋防所作，"皎如霜辉，温如玉粹"状写兔子洁白温润的形与性（D 项正确）。
- **易错点：** 三件兔文物朝代不同（B 项"都是西周"为本题错误项）；干支推算需天干按 10、地支按 12 分别取余，不可混用（2023 山东第 10 题）。
- **关联题目：** [行测-2023-山东-常识判断-010](../../../题库/答案/行测/常识判断/2023-山东-答案.md#行测-2023-山东-常识判断-010) → 正确选项 B（错因：不悉兔尊西周、白釉兔唐、青玉兔镇纸南宋分属不同朝代，B 称"都是西周"为误）

### 2️⃣. 二十四节气与物候、诗句对应（惊蛰·夏至立竿无影·谷雨）

- **大类：** 地理
- **关键要点：**
  - 1. 惊蛰（公历3月5—6日）——春季节气，华北3月仍可能受强冷空气/气旋影响降雪，“雪打惊蛰”可现“万里雪飘”。
  - 2. 立竿无影——仅当太阳近乎直射（夏至正午直射北回归线）时出现；北回归线标志（汕头、从化、封开、桂平、墨江）“立竿无影”在**夏至**而非冬至；冬至太阳直射南回归线，汕头日影朝北。
  - 3. 谷雨（公历4月19—21日）——“雨生百谷”，降水增多、秧苗初插；“一把青秧趁手青，轻烟漠漠雨冥冥”(虞似良《横溪堂春晓》)写江浙谷雨春耕。
  - 4. 物候诗句——“儿童急走追黄蝶，飞入菜花无处寻”(杨万里《宿新市徐公店》)写初春油菜花黄，2月北回归线附近初春可现。
  - 5. 解题法：先定节气公历日期与太阳直射点位置，再判“立竿无影”只属夏至；选非题常把冬至与立竿无影错配。
- **易错点：** 将“立竿无影”系于冬至（正确为夏至）是2023国考本题唯一错误项（答案C）；混淆惊蛰后仍可能降雪、谷雨江浙春耕雨景等正确描述。

### 3️⃣. 七十二候"候应"与节气时序排序

- **大类：** 地理
- **关键要点：**
  - 1. 物候历：五日一候、三候一气、六气一季、四季一年，二十四节气每季十八候，共**七十二候**；每候对应一"候应"（物候现象）。
  - 2. 关键候应的节气位置：东风解冻（立春初候，正月上旬）、草木萌动（雨水三候，正月下旬）、桃始华（惊蛰初候，二月上旬）、玄鸟至（春分初候，二月下旬）、雷乃发声（春分二候，二月下旬）、萍始生（谷雨初候，三月下旬）、鸣鸠拂羽（谷雨二候，三月下旬）、蚯蚓出（立夏二候，四月上旬）、蝼蝈鸣（立夏初候，四月初）、螳螂生（芒种初候，五月初）、蜩始鸣/蝉始鸣（夏至二候，五月下旬）、温风至（小暑初候，六月）、麦秋至（小满三候，四月下旬）、大雨时行（大暑三候，六月下旬）、桐始华（清明初候，三月上旬）、蟋蟀居壁（小暑二候，六月）、禾乃登（处暑三候，七月下旬）、寒蝉鸣（立秋二候，七月）、菊有黄华（霜降三候，九月下旬）、水始涸（秋分三候，八月下旬）。
  - 3. 解题法：以"立春→雨水→惊蛰→春分→清明→谷雨→立夏→小满→芒种→夏至→小暑→大暑→…"的节气轴定位每候，再判时序；注意同月内"初候/二候/三候"的先后。
  - 4. 易错时序：萍始生（三月下旬）早于蝼蝈鸣/麦秋至（四月）；蚯蚓出（四月上旬）早于螳螂生（五月）、温风至（六月）、水始涸（八月）；桐始华（三月上旬）早于蟋蟀居壁（六月）、禾乃登/寒蝉鸣（七月）、菊有黄华（九月）。
- **易错点：** 命题把跨月候应打乱（如把萍始生排到蝼蝈鸣之后、把水始涸排到温风至之前）；只有A项（立春→雨水→惊蛰→春分→谷雨→夏至）全程由早及晚（2023四川，答案A；注：该题未见于公考真题库2023四川省考卷，卷别待核验）。
- **关联题目：** [行测-2023-四川-常识判断-待核验-002](../../../题库/答案/行测/常识判断/2023-四川-答案.md#行测-2023-四川-常识判断-待核验-002) → 正确选项 A（错因：不悉各候应的节气位置，B/C/D三项时序均被打乱）

### 4️⃣. 文化地标与自然景观所在省市（卢舍那大佛·丹霞地貌·三江并流·河姆渡遗址）

- **大类：** 地理
- **关键要点：**
  - 1. 卢舍那大佛——**河南洛阳**龙门石窟（西山奉先寺，依武则天形象雕凿）；山西大同以**云冈石窟**著称，二者勿混。
  - 2. 丹霞地貌——陆相红色砂砾岩构成、具陡崖坡的地貌，全国广布；**贵州赤水丹霞**（青年期）为中国丹霞面积大、发育壮观区域之一。
  - 3. 三江并流——金沙江、澜沧江、怒江在**云南西北部**自北向南并行奔流约170千米的区域；不在四川宜宾。
  - 4. 河姆渡遗址——长江下游新石器时代早期遗址，位于**浙江宁波余姚**；不在浙江湖州。
  - 5. 解题法：文化地标/自然景观→锁定所在省市，凡"地标—省市"错配即选非/排除；山西大同(云冈)、河南洛阳(龙门/卢舍那)、贵州赤水(丹霞)、云南(三江并流)、浙江余姚(河姆渡)为高频对应。
- **易错点：** 卢舍那大佛误系山西大同（实为河南洛阳龙门）；三江并流误系四川宜宾（实为云南）；河姆渡误系浙江湖州（实为宁波余姚）（2025 天津第59题 B 项正确项即对应贵州赤水丹霞，A/C/D三项均错配）。
- **关联题目：** [行测-2025-天津-常识判断-059](../../../题库/答案/行测/常识判断/2025-天津-答案.md#行测-2025-天津-常识判断-059) → 正确选项 B（错因：A/C/D 三项地标与省市错配；正确项 B=贵州赤水丹霞）

## 五、生活常识

### 1️⃣. 惊蛰节气与物候科学解释

- **大类：** 生活常识
- **关键要点：**
  - 1. 惊蛰（3月5—6日）："春雷响，万物长"，气温回升、土壤解冻、春雷始鸣。
  - 2. 科学解释：蛰虫复苏的主因是**气温回升、土壤温度升高**，昆虫结束冬眠（变温动物，体温随环境变化）。
  - 3. 物候三候：桃始华、仓庚鸣、鹰化为鸠。
  - 4. 解题法：区分"科学主因"与"文学/民间表述"——温度是主因，雷声、雨水是伴随现象。
- **易错点：** 民间"春雷惊醒蛰虫"是文学化表述（2025深圳第27题 C 项为干扰）；勿将物候伴随现象当作科学主因。
- **关联题目：** [行测-2025-深圳-常识判断-027](../../../题库/答案/行测/常识判断/2025-深圳-答案.md#行测-2025-深圳-常识判断-027) → 正确选项 A（错因：不悉气温回升是蛰虫苏醒的科学主因）

### 2️⃣. 中医五行与五脏对应

- **大类：** 生活常识
- **关键要点：**
  - 1. 五行相生：木生火、火生土、**土生金**、金生水、水生木。
  - 2. 五脏对应五行：肝属木、心属火、**脾属土**、肺属金、肾属水。
  - 3. "土不生金"：脾为肺之母，脾虚则肺虚（小儿气喘）；治肺需补脾，即"培土生金"法。
  - 4. 解题法：抓"母病及子"关系反推属性——题干肺属金，其母为脾（土生金）。
- **易错点：** 五脏五行对应须记牢（肝木心火脾土肺金肾水）；易把脾误记属木或水（2024辽宁第16题）。
- **关联题目：** [行测-2024-辽宁-常识判断-016](../../../题库/答案/行测/常识判断/2024-辽宁-答案.md#行测-2024-辽宁-常识判断-016) → 正确选项 D（错因：不悉脾属土、土生金）

### 3️⃣. 消防安全知识

- **大类：** 生活常识
- **关键要点：**
  - 1. 消防车道净宽度不应小于4米。
  - 2. 电器着火、油类着火不能用水（用干粉/二氧化碳/泡沫油类）。
  - 3. 生活区域（家庭）应配干粉或水基型灭火器（非泡沫）。
  - 4. 高层民用建筑内严禁使用瓶装液化石油气。
- **易错点：** 误以为“生活区应配泡沫灭火器”（泡沫不适用电气火），2021四川第12题选C。
- **关联题目：** [行测-2021-四川-常识判断-012](../../../题库/答案/行测/常识判断/2021-四川-答案.md#行测-2021-四川-常识判断-012) → 正确选项 C（错因：不悉生活区宜配干粉/水基灭火器、泡沫不适用电气火）

### 4️⃣. 急救常识

- **大类：** 生活常识
- **关键要点：**
  - 1. 呕吐者取侧卧位（复原卧位）防误吸，非仰卧。
  - 2. 踝扭伤先冷敷（24—48h后热敷），忌早期热敷按摩。
  - 3. 冻伤用温水（约37—40℃）缓慢复温。
  - 4. 成人心肺复苏按压:通气=30:2（非10:2）。
- **易错点：** 误以为“呕吐仰卧防窒息”“踝扭伤热疗按摩”“心肺复苏10:2”（2025云南第16题选C）。
- **关联题目：** [行测-2025-云南-常识判断-016](../../../题库/答案/行测/常识判断/2025-云南-答案.md#行测-2025-云南-常识判断-016) → 正确选项 C（错因：不悉呕吐应侧卧、踝扭伤先冷敷、心肺复苏30:2）

### 5️⃣. 日常生活（蚊虫/酒精解辣/煤气/高血压）

- **大类：** 生活常识
- **关键要点：**
  - 1. 蚊虫叮咬：冷敷/碱性肥皂缓解，热敷加重肿胀瘙痒（错A）。
  - 2. 辣椒素为脂溶性，酒精（或食用油、牛奶）可溶解缓解“辣”手（对B）。
  - 3. 煤气泄漏：禁动火/开关电器，到室外关总阀，不可开灯/关灯触碰开关（错C）。
  - 4. 高血压者应适度规律运动（有助控压），非“少运动”（错D）。
- **易错点：** 误以为热敷消肿（应冷敷）；误以为煤气泄漏可先关灯（应禁触碰电器到室外处理）；误以为高血压者不宜运动。
