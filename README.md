# 公务员考试备考笔记

面向国考、省考备考者的结构化学习仓库，聚合行测、申论、真题解析与备考方法论，帮助使用者以更清晰的路径整理知识、练习题目并持续复盘。

## 项目简介

本仓库用于系统整理公务员考试备考资料，覆盖以下核心内容：

- `01-行测`：按科目沉淀知识点、解题技巧、例题精讲和易错点。
- `02-申论`：按题型组织作答框架、素材积累和实战拆解。
- `03-真题`：按考试类别、地区和年份归档历年真题与解析。
- `04-备考指南`：提供入门规划、阶段安排、刷题复盘和时间管理建议。

适用人群：

- 初次备考，需要建立完整学习框架的考生。
- 已开始刷题，希望提高检索效率和复盘质量的考生。
- 希望持续沉淀资料、共同维护笔记的备考伙伴。

项目目标不是堆砌资料，而是建立一套可检索、可复用、可扩展的备考知识库。

## 快速开始

### 在线浏览

直接在代码托管平台中按目录阅读对应笔记，适合碎片化查阅与快速定位。

### 本地使用

```bash
git clone <repo-url>
cd civil-service-exam-notes
```

建议阅读顺序：

1. 先阅读 `04-备考指南/01-入门规划` 与 `04-备考指南/02-阶段计划`，确定备考周期与学习节奏。
2. 根据个人短板进入 `01-行测` 或 `02-申论`，先学方法，再做专题训练。
3. 完成知识梳理后进入 `03-真题` 限时练习，并把错题回链到对应知识模块。
4. 每周结合 `90-模板/周复盘模板.md` 进行复盘，持续修订学习计划。

### 主要目录用途

| 目录 | 用途 |
| --- | --- |
| `01-行测` | 按科目组织内容，科目内统一采用 `知识点 / 解题技巧 / 例题精讲 / 易错点` 结构。 |
| `02-申论` | 按题型组织内容，聚合作答方法、框架模板、素材积累和实战拆解。 |
| `03-真题` | 按考试类别、地区与年份检索真题，便于回看趋势并与知识模块互相引用。 |

| `99-索引` | 提供学习路线图、关键词索引与更新日志，提升仓库扩展后的检索效率。 |

### 命名规范

- 顶层与主要子目录统一使用两位数字前缀，保证排序稳定。
- 模块名和目录名统一使用中文，避免中英混排造成检索分裂。
- 真题文件统一采用 `年份-考试类型-地区-模块-卷别-解析.md`。
- 普通知识型笔记统一采用 `主题-用途.md`，例如 `逻辑填空-高频成语总结.md`。
- 同一层级只按一个维度命名，不混用题型、阶段和资料类型。

## 模块使用指引

### 01-行测

建议路径：`知识点 -> 解题技巧 -> 例题精讲 -> 易错点 -> 对应真题`

使用方式：

- 先按薄弱科目切入，例如言语理解、数量关系或资料分析。
- 每个科目优先建立题型框架，再补充常见方法和高频陷阱。
- 做完专题练习后，把错题与对应知识点双向关联，形成自己的高频错因清单。

### 02-申论

建议路径：`题型方法 -> 框架模板 -> 素材积累 -> 真题拆解 -> 周期复盘`

使用方式：

- 先掌握归纳概括、综合分析、提出对策等基础题型的作答结构。
- 在应用文写作和文章论述中沉淀常用框架、标题写法和过渡表达。
- 素材积累不求多而散，重点围绕常考主题建立可复用表达与案例库。

### 03-真题

建议路径：`限时作答 -> 对照答案 -> 阅读解析 -> 回链知识模块 -> 记录复盘`

使用方式：

- 真题优先按年份完整训练，再按题型回看命题规律。
- 解析应聚焦审题思路、时间分配、得分点和失分原因，而不仅是答案本身。
- 行测真题与 `01-行测` 联动，申论真题与 `02-申论` 联动，避免题目与方法脱节。

### 04-备考指南

建议路径：`入门规划 -> 阶段计划 -> 刷题与复盘 -> 时间管理 -> 心态调整`

使用方式：

- 入门阶段先确定备考周期、目标岗位和日周学习节奏。
- 强化阶段关注刷题节奏、错题管理和阶段性复盘。
- 冲刺阶段重点收缩任务边界，维持稳定作息和临场状态。

## 贡献规范

## 选择题生成约定

项目级 Agent 规则见根目录 [`AGENTS.md`](AGENTS.md)。选择题必须将题目与答案拆分到 `题库/题目/<大类>/` 和 `题库/答案/<大类>/`，题目使用通用 Markdown 任务列表（`- [ ]`）呈现选项并链接到答案文件的对应锚点；题目和答案都要标注可追溯的具体来源，每题至少包含 3 个 `#标签`，且必须包含固定大类标签。可直接复制 [`90-模板/选择题模板.md`](90-模板/选择题模板.md) 与 [`90-模板/答案模板.md`](90-模板/答案模板.md) 开始新增题目。

题库仅收录公开发布且可核验的真题，不生成原创题、改编题或变式题。每道题必须标注完整考试出处和权威来源链接或出版物页码；无法核验的题目不提交。
