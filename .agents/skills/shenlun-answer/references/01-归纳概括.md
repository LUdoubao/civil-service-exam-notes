# 归纳概括

适用：设问要求概括、归纳、简述、梳理材料中的问题、原因、做法（对策）、成效或某事物的若干方面。

## 通用方法

所有概括题共用同一套读法，来自《概括问题》《概括原因》《概括对策1-3》《概括综合1-2》的「本节课复盘」：

1. **粗读定逻辑、定前置词**；**精读定内容、定关键词**。粗读不额外消耗作答时间。
2. 用**宏观、中观、微观三个维度盘点材料**（三层定义见 SKILL.md）。
3. **材料逻辑即答案逻辑**：材料的段间结构（总—分—总、总分、并列、递进）决定答案的结构。
4. 答案内部多用「总起句 + 并列分点」：总起句统领全篇，分点平行罗列不同维度，无明显先后时按材料顺序排。

## 字数压缩技巧

讲义「本节课复盘」给出同一组技巧，各份讲义措辞基本一致：

- 故事性材料和总结性表述并存时，保留总结性表述。
- 一级、二级、三级目录并列时，保留一级目录和二级目录。
- 学会合并动词；保大弃小。
- 「保留形容词＋事情」与「保留动词＋事情」两种措辞在不同讲义中并存，属于待裁决冲突，见 [07-待裁决冲突.md](07-待裁决冲突.md)。

## 分题型规则

### 概括问题

来源：《概括问题+5.141792200212.docx》，例题为「根据材料1，简述微短剧市场出现的乱象」，200 字，15 分。

- 参考答案按段落顺序一段一个核心问题，直接分点，未加总起句。
- 每题附带「段落主旨 + 段内逻辑 + 段间衔接」的逐段解析，把答案要点和材料段落一一对上。

### 概括原因

来源：《概括原因+5.161792200212.docx》，例题为「分析W县能够做好绿色发展的原因」，250 字，20 分。

- 全文口诀：总分逻辑 + 顺承递进逻辑。
- 答案口诀：**总起句 + 并列分点**。总起句写思想认知层面，六条要点从生态建设、文旅布局、业态创新、资源整合、农业发展、政务服务六个维度并列展开。
- 每条要点内部按「发现问题—创新举措—取得成效」「主体搭建—资源统筹—模式创新」这类小逻辑展开。

### 概括做法（概括对策）

来源：《概括对策1+5.81792200212.docx》《概括对策2+5.101792200212.docx》《概括对策3+5.121792200212.docx》。

- 《概括对策1》例题为「概括S市实施『幼有善育工程』的主要做法」，300 字，20 分。答案先写总领句（政府主导、家庭为主、多方参与，构建托育服务体系），再分 4 点。
- 《概括对策2》为各地信用修复工作的主要做法；《概括对策3》为各地公安机关高空抛物治理的主要做法，该篇材料为总—分—总结构，分述段统一是「背景／问题 → 具体举措 → 成效反馈」。
- 《概括对策1》复盘列出**概括题四个高频丢分坑**：
  - 时态坑：把未来规划当成已实施做法。原话把「将、未来、待XX后、接下来」列为不该写的内容，并称「以后做概括题永远不踩」；该绝对口径与其它讲义及已确认规则冲突，见 [07-待裁决冲突.md](07-待裁决冲突.md)。
  - 案例坑：把群众案例、单个园区的细节写进答案，浪费字数不得分。
  - 主观发挥坑：脱离材料瞎编，例如材料没提「加大财政投入」「完善法律法规」就不写。
  - 字数坑：超字数直接扣分，写完必须数字数，超了删修饰词，优先保核心踩分点。

### 概括综合

来源：《概括综合1+5.201792200482.docx》《概括综合2+5.221792200478.docx》。

- 《概括综合1》例题为「谈谈『绿色工厂』的『绿』体现在哪些方面」，200 字，20 分。答案用「绿在景观／能源／产品／办公／原料」的**统一句式加维度词**分列，逐段对应材料。
- 《概括综合2》例题为「用一段话归纳概括各地『花式』普法的做法及其成效」，250 字，20 分。该题给出的要素口径是**主体 + 核心创新模式 + 具体做法 + 核心成效**，六个案例按材料顺序并列，用一段话串联而不分点。
- 该篇「材料到答案的逻辑转化要点」写明两步：**要素提取**（从每个案例剥离「做法」和「成效」，剔除背景描述和人物对话）；**语言凝练**（把冗长表述压缩为申论语言，保留「订单式」「动漫普法」「评弹形式」这类核心关键词）。

## 小结（判分视角）

判分时看三件事：要点是否落在材料划定的逻辑单元上、每个要点是否带材料核心词、字数是否守住。概括题的收益主要来自不遗漏和不超字数。
