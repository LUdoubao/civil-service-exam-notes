# 作答收敛与核字

适用：正式作答、批改用户答案、按标准答案对比多份答案。

## 标准答案锚定

- 用户提供标准答案时，先抽取：一级点数量、每点动作链、材料核心词、分值口径、字数口径。
- 标准答案优先于模型另行生成的结构；不得为了显得完整而增删一级点。
- 标准答案未给分值表时，按一级点等权折算估分，并标注为非官方。
- 标准答案与材料或讲义冲突时，按用户指定标准答案评分，单独记录冲突，不擅自修正。
- 已知讲义例题、标准答案或材料有明确总括句结构时，作答收敛先**对齐其口径**——一级点数量与边界以既有结构为准，再决定增减；与既有结构不一致时，在「合并、取舍与排序理由」中说明差异依据，不得脱离已知结构自造分点。

## 一级点收敛

- 先合并候选点，再写正式答案；同一主体、同一对象、同一作用链优先合并。
- 20 分、300 字题通常保留 4 至 6 个一级点；材料呈五类路径时，默认收敛为 5 个一级点。
- 同一路径内的供给、设施、调度、管理等环节，是否拆点取决于标准答案、题目要求和字数；不得按自然段机械拆点。
- 每个一级点用 4 至 8 字前置词，内部保留核心动作、对象或手段；只写方向不写做法不能得分。
- 字数超限时先合并同类一级点，再删案例、数据、成效、引语和修饰词，不删材料核心词。
- 概括题默认执行「数据清零」与「目录层级上提」（见下两节），不因字数有富余就保留数字或三级目录枚举。

### 上级锚点优先

- 收敛前先识别材料的**上级锚点**：总结性总括句、标准答案或讲义例题的一级点结构。它作为收敛上限，决定一级点数量与边界。
- 「边界保留」不得机械执行为「动作不同就自动拆点」。下位动作词（如「警长兼任副书记」「民警扎根社区」「三熟三清」这类二级表述）默认回挂到上级采分点之下，不因动作不同而单独升格为一级点。
- 升格门槛：能独立承担一条完整「主体—动作—对象—结果」链，且材料有明确分界标志（独立段落、独立维度、独立前置词）的，才允许升格。

### 前置词规范

- 一级点前置词优先采用**动宾式四字短语**，并尽量沿用材料原词。
- 材料出现「党建引领基层治理」「激活群防群治力量」这类现成表述时直接沿用，不另起名词短语，不造生硬简称（如「标准建室」）。

## 案例段结论回挂

- 凡宏观层功能判定为「举例／佐证」的案例段，其候选要点必须回挂到与之配套的机制段或总结段的采分点下，不得单独成点。
- 回挂时以总结段的总结性表述为主干，案例段只提供方法词佐证；案例段找不到对应总结段时，该案例通常不产生独立采分点。

## 总起句门禁

- 总起句不是默认项。材料没有明确总结性总括，标准答案或讲义例题没有总起，题面也不要求总起时，直接写分点。
- 概念定义、政策背景、园区或项目介绍不能自动充当总起句。
- 确有总起需要时，控制在 20 至 25 字左右，且不能替代具体采分点。

## 数据清零

- 概括题正式答案**一律不写具体数字**，除非题干设问对象本身就是数字（如“问规模多大”）、或标准答案明确保留。
- 受约束的对象包括：人数、金额、百分比、数量、时间跨度、建成数等所有量化数据。例如“305 名警长”“90% 以上时间”“3666 个单元”“324 个警务室”“3 分钟”均删，只保留“扎根社区一线”“实现辖区全覆盖”“一村居一警务室”这类做法程度词。
- 数字只在“标准答案保留它、或它能独立承担一个采分点”时才例外；多数情况下数字只佐证规模，删去不影响要点成立。若拿不准，按“宁可删、不保留”处理。

## 目录层级上提

- 材料枚举“一级目录—二级目录—三级目录”并列时，答案只保留一级、二级目录，删三级目录及以下的罗列。
- 典型场景：做法类材料用“整合 A、B、C、D 等力量”罗列整合对象，答案只写“整合多方/多元力量”，不逐项照抄“物业、企事业单位保安、退休党员、志愿者”。枚举对象本身不是采分点，“整合＋组建”才是动作采分点。
- 判断方法：先识别动作词（整合、组建、开展、制定），再识别其宾语是否是一串并列名词；是则用“多方/多元/社会力量”等上位词概括，保留动作与结果，删宾语枚举。若标准答案保留了某枚举项，以标准答案为准。

## 表述保真

- 正式答案优先沿用材料核心词，只做压缩和衔接。
- 不得用材料未出现的概念替换原意。例如材料写“储存后作气肥”，不得改写成“捕集”“回收”或“碳交易”；材料写“生产流程减碳”，不得替换成“供应链降碳”。
- 区分做法、原因、成效、动机。设问要求路径或做法时，成效、动机、政策背景、案例数据、产品收益不独立计分。
- 成效词只有在材料或标准答案把它作为要点时才保留。

## 字数预算与核算

- 以正式作答内容为核算对象，不计算审题、分析、证据卡、答案提纲和说明文字。
- 300 字、5 点题：每点约 45 至 55 字，正文先控制在 250 至 285 格，预留 15 至 50 格；限字越紧，越要先合并再压缩。
- 正式答案完成后按占格口径逐字核算，标注为“估算”，不得声称是阅卷精确计格。
- 不采信文件或模型自报字数；自报值只能用于比对，不能作为最终依据。
- 如使用 `scripts/count_grid.py`，以脚本对正式作答区重复核算；脚本不可用时也必须重新逐字核算。

## 完整性对表

正式答案输出前内部核对：

| 检查项 | 要求 |
|---|---|
| 标准点覆盖 | 每个标准一级点都有对应答案句 |
| 动作链完整 | 核心动作、对象、手段、必要结果均保留 |
| 表述保真 | 未把材料事实替换成其他概念 |
| 数据清零 | 未出现人数、金额、百分比、数量、时间跨度等具体数字（设问对象即数字的除外） |
| 目录上提 | 未逐项罗列三级目录枚举（如“物业、保安、退休党员、志愿者”），已用上位词概括 |
| 锚点一致 | 一级点数量与边界对齐已知标准答案／讲义例题／总括句结构，未擅自增减 |
| 案例回挂 | 无案例段提炼的动作被单独升格为一级点 |
| 前置词 | 采用动宾式短语并沿用材料原词，无生硬简称 |
| 总起句 | 确实需要才写，且不占压采分点 |
| 字数 | 正式答案在题面限额内，自报值与核算值一致 |

任一检查项不通过，先重写正式答案，再输出。
