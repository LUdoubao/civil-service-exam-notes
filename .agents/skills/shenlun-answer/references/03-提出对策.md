# 提出对策

适用：设问要求梳理问题并提出对策建议、阐述原因并提出下一步建议、草拟若干措施的主要内容、撰写工作建议或工作方案。

## 复合对策

来源：《复合对策1+6.11792200480.docx》《复合对策2+6.31792200486.docx》《复合对策3+6.51792200498.docx》。

三篇例题的共同题干结构都是**两问并列**：「先梳理完所有问题，再提出建议」；《复合对策3》的变体是「阐述原因，并提出下一步工作建议」。要求普遍落在「全面准确、具体可行、有针对性」上。

### 结构

- **先集中列问题，再集中列建议**，两块之间不交叉。这一点由题干直接规定，三篇例题一致。
- 建议与问题**一一对应**：材料呈现几类问题，就写几条建议，逐条对上。《复合对策2》为 4 条问题对 4 条建议，《复合对策3》为 6 条原因对 6 条建议。
- 每条建议内部写「动作 + 具体做法」，避免只写方向。示例：「强化权益保障：明确房屋回收、到期续租、改造补偿等规定」。
- 问题与建议都要点出主体和对象，不能只写现象。

《复合对策1》的示例答案列了 4 条问题却只给 3 条建议（「检测能力不足」无对应建议），与一一对应原则不一致，属于待裁决事项，见 [07-待裁决冲突.md](07-待裁决冲突.md)。

### 读材料

- 材料多为**问题导向型线性叙事**：背景铺垫 → 矛盾引爆 → 呈现对立双方诉求 → 揭示管理困境 → 专家定调给出解决原则。
- 核心得分点集中在**段首总起句和段尾总结句**，段中案例是佐证。
- 案例段常用「个体案例 + 数据／本质提炼」的写法，提炼句才是要点来源。
- 出现专家观点时，往往是对策的总纲领。示例中社会学专家提出的「多方发力、找到最大公约数」就是该题建议的统领原则。
- 问题顺序通常按事情发展的先后展开（如资金 → 人才 → 公共服务 → 市场竞争），答案顺此排列即可，不必另排。

## 措施内容

来源：《措施内容+6.81792200466.docx》，例题为「T市拟制定《关于进一步促进全市物流行业数字化发展的若干措施》，请草拟其主要内容」，400 字，25 分，要求「紧扣资料，内容全面，重点突出，结构完整」。

- 材料是政府专题会议纪要：总起段交代背景与议题，中间是分部门汇报，末段市长总结给出问题诊断与工作部署，直接对应「制定措施」这一任务。
- 答案结构为**总体要求 + 具体措施 + 保障机制**：总体要求取自总结段的形势判断与问题指向，具体措施逐条对应各部门汇报，保障机制取自总结段的部署。
- 分部门汇报按「物理基础 → 市场主体 → 核心环节 → 产业链延伸 → 民生细分领域 → 要素保障」的内在顺序排列，每条措施内部按「总起—成果／问题—下一步计划」展开。
- 题面出现「主要内容」时，按 [05-格式与字数.md](05-格式与字数.md) 的规则不需要写规范公文格式。

## 工作建议与工作方案

来源：《公文写作格式大盘点11792200462.docx》《公文写作格式大盘点21792200492.docx》中的例题。

- 工作建议：题干常给「进一步强化举措、巩固成果、形成长效机制」，要求在措施之外补上长效视角。结构用「关于……的工作建议」标题 + 问题背景 + 并列建议，结尾可用「以上建议请参考」。
- 工作方案（如农村改厕工程、评选活动方案）：结构为**总体目标 + 主要任务 + 保障措施**，主要任务逐条写「怎么做 + 谁来做 + 做到什么程度」。

## 小结（判分视角）

对策题的分数集中在两处：问题是否梳理完整（对应材料的问题类别数），建议是否与问题逐条咬合且可操作。只写方向不写做法的建议拿不到高分。
