# 综合分析

适用：设问要求谈谈变化、启示、对某句话或某个新模式的理解与认识。

## 变化分析

来源：《变化分析+5.301792200490.docx》，例题为「结合材料中鲁师傅广合烧饼发展过程中的四个台阶，谈谈执法方式发生了哪些变化」，300 字，15 分。

- 核心句式是**「从……到……」**：每条要点先把旧状态和变化后的状态对举，再补变化后的具体做法与成效。
  示例：「从单纯取缔到以柔性引导和规范准入推动合法经营」「从现场检查到以智慧监管和信用分级推动现代化管理」。
- 材料常用「现实—回忆—现实」的环形结构，答案对应用「总—分—总」。
- 四条变化要点与材料的四个逻辑单元、人物发展的四个台阶一一对应，题干的「几个台阶」是天然的分点依据。
- 变化之间通常是**时间顺承 + 逻辑递进**，答完要能看出「管得住 → 管得好 → 服务好 → 智慧管」这类升级线索。

## 启示分析

来源：《启示分析+5.281792200495.docx》，例题为「谈谈Z市帮扶小微企业的做法对我们有哪些启示」，300 字，20 分。

- 材料多为「微观案例引入 → 宏观总领定调 → 并列展示现有举措 → 部署未来长效规划」，答案对应用「承上启下、总分、并列、递进」四条线。
- 参考答案按五个方面展开：开展指导服务、落实减税降费、提供个性化融资支持服务、强化培训、明确发展规划。
- 该题参考答案把材料末段的中长期发展规划列为要点，说明**启示类题目可以纳入未来指向的内容**。
- 讲义未明确要求把「Z市做法」改写成一般化表述。写成「某市做了什么」还是「应当怎么做」，按设问措辞定；设问问「对我们有哪些启示」时，优先给出可迁移的做法而不是复述案例细节。

## 词句理解

来源：《词句理解1+5.241792200471.docx》《词句理解2+5.261792200475.docx》。

### 结构

- 两篇材料都是递进式逻辑，答案结构对应为「释义／定性 → 分述解释 → 总结意义」。
- 《词句理解1》例题为「谈谈毛所长这句话的意思，以及他为什么这么说」，250 字，10 分。答案分两块：第一块用一句话解释这句话的意思；第二块以「原因：」领起，分点列村民观念转变、机构改革打破警种壁垒、借力技术赋能。
- 《词句理解2》例题为「谈谈你对『体检式监管、服务型执法』这一执法新模式的理解和认识」，300 字左右，15 分。答案先总体定性（是 L 区推行的执法新模式，监管部门既是执法者又是服务员，获得企业认可、值得推广），再分别解释「体检式监管」帮企业发现问题、「服务型执法」帮企业解决问题，最后总结推行意义。

### 读材料

- 材料常见「抛出事件 → 剖析问题 → 凸显矛盾 → 解决问题 → 提炼主旨」，段间用承接、转折、因果、升华衔接，末段往往给出概念命名与推行目的，是主旨核心句所在。
- 段内拆解要标出逻辑类型：总分、转折、顺承、并列、因果、解释说明。讲义示例逐句标注「设问总起→陈述事实→转折铺垫」「转折引困境→总分述危害→因果推结果」。
- 注意区分**释义句**与**原因句**：设问同时问「什么意思」和「为什么这么说」时，答案必须分两块，不要把原因写进释义。

## 通用要求

- 分析题的要点同样落在材料上，先定位承载信息的段落，再压缩成要点，不要写成读后感。
- 材料中出现的专家观点、部门表态、案例结局都可能承载要点，但只有与设问动作直接相关的才写进答案。
