# 申论小题作答

面向国考、省考申论小题，服务备考新手：既要给出可直接上考场的正式答案，也要把答案是怎么从材料里得出来的过程讲清楚。

## 知识来源

规则来自仓库 `02-申论/袁东/` 下的 26 份讲义（含正文、例题、解析、答案和嵌入图片中的表格）。不要用公开资料覆盖讲义规则；公开资料只能用于补充核验，且必须标明来源。

- 题型方法与长篇示例：[references/01-归纳概括.md](references/01-归纳概括.md)、[references/02-综合分析.md](references/02-综合分析.md)、[references/03-提出对策.md](references/03-提出对策.md)、[references/04-应用文写作.md](references/04-应用文写作.md)
- 公文格式、占格与字数口径：[references/05-格式与字数.md](references/05-格式与字数.md)
- 规则到讲义的定位表：[references/06-讲义出处索引.md](references/06-讲义出处索引.md)
- 讲义内部冲突，裁决前不得自行选择：[references/07-待裁决冲突.md](references/07-待裁决冲突.md)
- 作答收敛、保真与核字：[references/08-作答收敛与核字.md](references/08-作答收敛与核字.md)

先按下面第二步确定题型，再只读取该题型对应的参考资料；写应用文时同时读格式与字数。

## 一、判断运行模式

- 用户给出材料和题干要求作答：走「作答流程」。
- 用户给出自己的答案稿、要求批改或估分：走「批改流程」。
- 用户既要求作答又要求批改：先按作答流程生成参考答案，再按批改流程评估用户答案。
- 用户提供标准答案并要求批改、估分或横向对比：走「批改流程」，标准答案优先，不另行生成参考答案。

## 二、审题与题型路由

审题字段按题型动态提取，不套用统一清单：只提取会改变作答任务的要素。常见要素有作答对象、身份、受众、核心动作、材料范围、文种、字数、语气与格式要求，题面没写的项目不要臆造，需要时标为「题面未说明」。

按**核心作答动作**路由，题干里的「概括」「分析」「启示」「推荐」等显性词只作辅助判断：

1. 先拆设问要求的动作，例如「概括做法」与「分析原因」是不同动作。
2. 动作直接对应讲义细分题型时，用该题型的规则。
3. 一道题含多个动作时拆成子任务分别处理，最后按题面顺序整合。
4. 讲义没有对应细分题型时，按设问拆任务自建步骤，不要硬套现成模板。

## 三、逐段三层分析

对**每一个自然段**先粗读、再精读，两层同时给出三层分析。不要把材料按段落编号罗列一遍了事，重点是判断这段和本题的关系。

- 粗读定逻辑、定前置词，精读定内容、定关键词。
- **宏观层**：这段的核心内容、段落功能（总起、分述、过渡、总结、举例佐证等），以及它对本题作答的贡献。
- **中观层**：段内意群或逻辑单元怎么划分，单元之间是什么关系，哪些单元承载本题所需信息。
- **微观层**：逐句识别主体、行为或状态、对象，以及必要的条件、原因、结果等关键词；区分材料原意与自己的推断，压缩成候选得分点。

逻辑词按功能分类并追踪影响：转折、因果、递进、并列、总结、条件、时间、范围。记录它们对段落结构、要点边界、候选得分点的作用，不要只把连接词抄一遍。

分析完成后必须把候选结论收敛为可作答的一级点；逐段分析不是正式答案的分点。

## 四、证据与要点

每个候选得分点用结构化证据卡登记：段落号、原文关键词或短引、逻辑功能、候选要点、原文或推断标记、对应的子任务。证据卡是后面取舍的依据，也是批改时判定「蹭点」和「真采分点」的依据。

合并与去重按**同义归并、边界保留**：同一主体、同一对象、同一作用的表达合并；主体、对象、条件、原因、结果任一不同的，即使表述相近也分别保留。

先按上述规则合并候选点并确定一级点，再进入作答收敛和字数预算；一级点数量和总起句取舍见作答收敛参考。

材料之外的知识严格让位给材料：只有题目明确要求补充政策依据、身份职责或联系实际时才可以引入，并说明引入理由。

要点按材料逻辑或题目逻辑排序。材料逻辑就是答案逻辑，优先顺着材料自身的顺序走。

## 五、写出答案

正式答案先收敛、再落笔。先按 [references/08-作答收敛与核字.md](references/08-作答收敛与核字.md) 确定一级点数量和字数预算，再沿用材料原句删改衔接，保留材料核心词；不得把逐段分析直接抄成答案，不得用材料未出现的概念替换原意。

总起句不是默认项：材料有明确总结性总括、标准答案或讲义例题本身有总起、或题面要求时再写。题目给定标准答案时，以标准答案的一级点、动作链和核心词为作答锚点，不另造结构。

字数先按题面规则估算，再对正式答案逐字核算；标注为「估算」，不要冒称精确阅卷计格。核算只针对正式作答内容，不计分析过程，也不采信模型自报字数。标题、称谓、落款是否计入，按题目要求决定；题目没写清楚时说明本次采用的估算口径。占格与标点的细节见格式与字数参考资料。

应用文以文种规范为底、题面要求优先：题面明确要素、限定字数或给出示范时，按题面裁剪并说明取舍。

## 六、输出骨架

默认输出完整考场分析链路，最后单独给正式答案：

1. 审题拆解（按题型提取要素，指出作答任务和陷阱）
2. 相关段落逐段追溯（每段粗读结论、精读结论、宏观／中观／微观三层结果）
3. 材料信息到候选要点的映射（证据卡）
4. 合并、取舍与排序理由
5. 答案提纲
6. 答案完整性对表
7. 字数核对（按占格口径核算）
8. 正式答案

只展开与本题有关的段落：无关段落不展示，只保留筛选后的逐点材料追溯。用户只想要答案时，可以压缩前面的分析，但正式答案和字数核对必须保留；答案完整性对表可在内部完成，不强制展示。

## 七、批改流程

用户提供标准答案时，先抽取其一级点、动作链、分值和字数口径，作为绝对基准，不另行生成参考答案；未提供标准答案时，先生成参考答案，再评用户答案。

1. 有标准答案时只解析标准答案，拆成互不重复的独立信息点；没有时才依据题目和材料形成参考答案。按重要性分配题目分值；格式、逻辑、字数另作调整项，避免对同一问题重复扣分。
2. 按四个维度诊断：核心要点覆盖、要点准确程度、逻辑组织、格式与字数。
3. 给出估分区间和把握度。题目没有评分细则时也要给区间，并按题目分值决定区间宽窄，同时标注这是非官方估分。
4. 列出已覆盖、遗漏、偏差的采分点，逐点附材料依据。
5. 给修改建议，再给修改后的参考答案；用户给了标准答案时，不得改写该标准答案的结构和核心词。
6. 批改对象只取正式作答，字数按占格口径重算，不采用文件或模型自报值。

用户提供的标准答案或参考答案是评分的绝对基准。与官方细则不一致时，保留其计分口径，同时指出版本差异并说明估分的不确定性。

## 八、暂停与冲突

- 题目材料缺页、关键句不完整、图片文字不可辨时整题暂停，指出缺失位置和受影响的子任务，等材料补齐再作答。
- 讲义规则之间出现冲突，且无法按题型或题干消解时：列出冲突双方的规则与出处，暂停该部分作答，请用户裁决，不要自行挑选一方。裁决结果确认后再写入本 Skill。
- 讲义中疑似文字提取错误的表述，能由上下文明确确定时按修复后的意思理解；未核对版面的修复文字不当作袁东原话引用。
- 用户提供的标准答案与材料或讲义不一致时，按用户指定标准答案评分，记录差异，不擅自更正。
